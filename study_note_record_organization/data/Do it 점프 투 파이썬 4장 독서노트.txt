1. 홀수, 짝수 판별하기
주어진 자연수가 홀수인지, 짝수인지 판별해 주는 함수 is_odd를 작성해 보자. iss_odd함수는 홀수이면 True, 짝수이면 False를 리턴해야 한다.

def is_odd(number):
	if number % 2 == 1:
		return True
	else:
		return False

2. 모든 입력의 평균값 구하기
입력으로 들어오는 모든 수의 평균값을 계산해 주는 함수를 작성해 보자. 단 입력으로 들어오는 수의 개수는 정해져 있지 않다.

def avg_numbers(*args):
	result = 0
	for i in args:
		result += i
	return result / len(args)
