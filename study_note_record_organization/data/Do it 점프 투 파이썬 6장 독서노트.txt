함수 이름은? gugu로 짓자
입력받은 값은? 2
출력하는 값은? 2단(2, 4, 6, 8, 10, ... 18)
결과는 어떤 형태로 저장하지? 연속된 자료형이므로 리스트!

def gugu(n):
    result = []
    i = 1
    while i < 10:
        result.append(n*i)
        i = i + 1
    return result

while True: # 무한 루프
    try: # 예외 발생 가능성이 있는 코드만 try 블록 안에 넣습니다.
        dan_str = input("단을 입력하세요 : (종료는 0를 입력하세요) ") # 입력은 일단 문자열로 받습니다.
        dan = int(dan_str) # 숫자로 변환 시도
    except ValueError: # 숫자로 변환할 수 없을 때 발생하는 예외 (가장 흔한 경우)
        print("잘못된 입력입니다. 숫자를 입력해주세요.")
        continue # 다음 루프로 넘어가서 다시 입력을 받습니다.
    except Exception as e: # 혹시 모를 다른 모든 예외를 잡을 때
        print(f"예상치 못한 오류가 발생했습니다: {e}")
        continue # 다음 루프로 넘어가서 다시 입력을 받습니다.

    if dan == 0:
        print("구구단 프로그램이 종료되었습니다.")
        break # 0을 입력하면 루프를 종료합니다.
    elif dan < 1 or dan > 9: # 1~9단 외의 숫자를 입력했을 경우 (선택 사항)
        print("구구단은 1단부터 9단까지 있습니다. 다시 입력해주세요.")
        continue
    else:
        print(gugu(dan)) # 올바른 입력일 경우 구구단 출력

게시판 페이징하기

함수 이름은? get_total_page
입력받는 값은? 게시물의 총 개수(m), 한페이지에 보여 줄 게시물 수(n)
출력하는 값은? 총 페이지 수

총 페이지 수 = (총 게시물 개수 / 한 페이지당 보여 줄 개수) + 1
전체 게시물을 한페이지당 포함할 수 있는 게시물 수로 나눠서 총 페이지수를 계산하는 것 같군.... + 1을 하는 이유는 뭐지?
남는 게시물이 있을떄 한페이지씩 더 만들어야하기때문에 1씩 더하는 것 같음


def get_total_page(m, n):
    if m % n == 0:
        return m // n # 총페이지수를 한페이지에 표시할 수 있는 게시물로 나누었을때 0이 되면 +1을 하면안되서 if문으로 제약을 검
    else:
        return m // n + 1 # m을 n으로 나눌 떄 소수점 아래 자리를 버리기위해 // 연산자 사용

print(get_total_page(5, 10)) # 1출력
print(get_total_page(15, 10)) # 2출력
print(get_total_page(25, 10)) # 3출력
print(get_total_page(30, 5)) # 6출력
print(get_total_page(30, 2)) # 15출력
print(get_total_page(30, 10)) # 3출력
print(get_total_page(30, 30)) # 1출력
