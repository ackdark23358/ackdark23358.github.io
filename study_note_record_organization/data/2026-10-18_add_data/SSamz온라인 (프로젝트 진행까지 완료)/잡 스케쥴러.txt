<service
	android:name= ".MyJobService"
	android:enabled="true"
	android:export="true"
	android:permission="android.permission.BIND_JOB_SERVICE"> 
</service>


class MyJobService: JobService(){
	override onCreaate()	override onDestory()
	override onStartJob() <= background 처리업무
	override onStopJab() <= 비정상 종료될떄
}


onStartJop() 리턴값 
(false: 벡그라운드 작업이 완벽히 종료 되었다.
true: 벡그라운드 작업이 아직 완전히 종료되지 않았다.)
onStartJob() 함수에서 false 리던

*onStartjab() 에서 시간이 오래걸리는 작업을 Thread로 하고있다면 true 를 리턴해서 잠시 기다렸다가 실행
onStopjab() 은 비정상 종료될때만 실행 된다. 조건이 바꼇을때 혹은 외부에서 캔슬시켰을때

잡스케쥴러에 직접접근하는게 아니라 데이터를 담고 시스템에 요청을 하고 잡스케쥴러 에서 onStartJab() 
뽑아서 사용한다.
