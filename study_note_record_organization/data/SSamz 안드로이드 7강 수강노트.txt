## 07-1 레이아웃 LinearLayout

레이아웃
레이아웃 : ViewGroup + Add된 View들 어떻게 배치
LinearLayout
RelativeLayout
FrameLayout 중첩 구조 유용
GridLayout 로우 칼럼 구조 유용
ConstraintLayout
개발자 선택상 Linear Relative Constraint 상호 대체가 가능하다.
선형으로 배치 Linear Layout
orientation속성 vertical , horizental 가로 세로
중첩구조가 가능해서 row cal 구조도 대체 할 수 있다.
여백을 채우는 layout_weight 속성 비율로 뷰를 배치
스크롤링 되는 뉴스화면구성에서 그만보기 버튼을 하단에 고정시키고 싶을떄
weight 속성은 동일레이아웃 내에서 적용이되야한다.
height 속성을 0을 주고 weight 속성을 사용해서 화면을 배치하는 구조도 주로 사용된다.
gravity와 layout_gravitiy
둘다 정렬인데 view내 정렬이 gravity
부모 영역에서 정렬
gravity = "left | bottm"
layout_gravity = "conter_horizental"

## 07-3 FrameLayout

겹쳐서 배치 - FrameLayout
visibility 속성을 주로 사용해서 뷰를 배치할떄 사용하는 레이아웃
텝 레이아웃 에서 사용하기도 한다.
엑티비티 파일
package com.example.chapter7.layoutPra
import androidx.appcompat.app.AppCompatActivity
import android.os.Bundle
import android.view.View
import com.example.chapter7.databinding.ActivityFrameLayoutPraBinding
class FrameLayoutPra : AppCompatActivity() {
override fun onCreate(savedInstanceState: Bundle?) {
super.onCreate(savedInstanceState)
val binding = ActivityFrameLayoutPraBinding.inflate(layoutInflater)
setContentView(binding.root)
binding.button.setOnClickListener {
binding.button.visibility = View.INVISIBLE
binding.imageView.visibility = View.VISIBLE
}
binding.imageView.setOnClickListener {
binding.button.visibility = View.VISIBLE
binding.imageView.visibility = View.INVISIBLE
}
}
}
xml 파일
<?xml version="1.0" encoding="utf-8"?>
<FrameLayout xmlns:android="http://schemas.android.com/apk/res/android"
xmlns:app="http://schemas.android.com/apk/res-auto"
xmlns:tools="http://schemas.android.com/tools"
android:layout_width="match_parent"
android:layout_height="match_parent"
tools:context=".layoutPra.FrameLayoutPra">
<Button
android:id="@+id/button"
android:layout_width="match_parent"
android:layout_height="wrap_content"
android:text="Button" />
<ImageView
android:id="@+id/imageView"
android:layout_width="wrap_content"
android:layout_height="wrap_content"
android:src="@mipmap/ic_launcher"
android:visibility="invisible"
android:clickable="true" />
</FrameLayout>
