1) path 모듈

운영체제간 파일 경로를 사용하는 구분자가 다른데 이걸 통일되게 관리하여 사용할 수 있게해준다.
(mac은 /, 윈도우는 \ 구분자를 사용한다.) 그리고 파일명, 디렉토리, 확장자를 분해해서 필요한 정보만 사용할 수 있다.
상대적 위치(./, ../)를 참조하는 상대경로, 루트(/) 부터의 경로를 참조하는 절대경로

path모듈과 관련된 함수들

dirname, filename, __dirname, __filename으로 어디서나 사용가능
basename, extname, parse

2) File System 모듈

파일스트리밍, 새로운 파일 디렉터리 만들기, 파일과 디렉터리 살펴보기를 할 수 있게 해준다.
현재는 폴더 이전에는 디렉터리라고 표현하였다.

프라미스를 사용, 콜백 사용, 동기 처리사용하는지에 따라서 함수의 이름과 사용방식이 조금씩 차이가 있다.
aync가 붙은 함수는 동기 붙지 않은것은 비동기라 생각하자.

FS모듈과 관련된함수들

readdirSync, readdir
readFileSync, readFile
writeFileSync, writeFile
existsSync
writeFile
appendFileSync, appendFile
unlinkSync, unlink
mkdirSync, mkdir
rmdirSync, rmdir
rmSync, rm

버퍼는 데이터를 메모리에 저장하고 직접 다룰때 사용하고 스트림은 데이터를 효율적으로 읽고 쓸때 사용하는 개념
청크는 버퍼링과 스트리밍을 할때 다루는 가장작은 단위
파이브는 한꺼번에 처리할때 효율 적으로 처리
버퍼에저장하고 스트리밍을하여 데이터를 주고받을때 주로 사용되는 리더블 스트림, 라이터블 스트림, 듀플렉스 스트림

책에서는 자주사용되는 리더블 스트림과 라이터블 스트림

전반적으로 기술문서를 많이 안읽어서 인지 사용법자체가 낯설게 느껴졌다.
자주사용되고 중요한 모듈과 함수들을 하나씩 실행해보면서 익혔는데 내가 원하는 프로그램에 어떤 모듈과 함수를 써야할지는 아직도 난해하기도하고 ChatGPT의 도움을 받아서 연습해봐야할 거같다.
