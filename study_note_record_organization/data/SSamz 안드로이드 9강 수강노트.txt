## 09-1 리소스 종류와 특징

09-1 리소스의 종류와 특징
09-1 리소스
res 폴더
drawable - 이미지
layout - ui xml
mipmap - app icon
values - 기타등등 문자열 값
animator - 속성 에니메이션 xml
anim - 트윈 에니메이션 xml
color - 색상 상태 목록 정의 xml
drawable - 이미지 소스
정적에니메이션 0.5만에 화면에서 사라진다.
고정적인 에니메이션 같은경우 xml로 지정한다.
세부적인 리소스 폴더
mipmap - 앱실행 레이아웃 리소스
layout - 레이아웃 xml
raw - 원시 형태로 이용되는 리소스 파일
values - 단순 값으로 이용되는 리소스
font - 글꼴 리소스
=============================
*menu - 메뉴 구성 xml
*xml - 특정 디렉터리가 정의되지 않은 나머지 xml 파일
다이얼로그 구성이나 커스텀 메뉴구성 할때 사용되기도 한다.
xml 이미지 속성
<shape> rectangle, oval, line, ring ...
<corners>둥근모서리 shape값이 rectangle 일때
<gradient> 그라데이션
<size> 도형의 크기
<solid> 도형의 색상
<stroke> 윤곽선
drawable/ a.png
layout/ b.xml
values/ string.xml, diemnsion.xml(글자 사이즈), color.xml)
뷰 바인딩
viewBinding{
enabled=true
}

## 09-3 폰 화면 크기별 설정

px 로 수치값을 조정해서 폰크기별 해상도 작업을 할수도 있지만
dp나 sp 로 작업하면 기기별 호완성있는 글자크기를 작업해준다.
근대 kt 파일 에서 작업하려면 px로 작업할수 밖에 없어서
values/dimens.xml 에 사이즈를 dp, sp , 이름 속성을 지정해놓고
R.dimens.a 같은 방식으로 사용하기도 한다.
기기의 화면 정보를 가져오는 방법
과거에는 displayMetrics 로 크기정보를 가져왔었지만
30버전 이상부터는 (deprecation).windowMetrics를 이용
해야 한다.
if(Build.VERSION.SDK_INT >= Build.VERSION_CODE.R){
윈도우 메트릭스
}else{
디스플레이 메트릭스
}
가로값, dp값, 세로값, ldp폰이냐 m xd냐도 얻을 수 있다.
메인엑티비티 파일
package com.example.chapter9.test
import android.hardware.display.DisplayManager
import android.os.Build
import androidx.appcompat.app.AppCompatActivity
import android.os.Bundle
import android.util.DisplayMetrics
import android.view.Display
import android.view.WindowMetrics
import com.example.chapter9.test.databinding.ActivityPhoneSizePraBinding
class MainActivity : AppCompatActivity() {
override fun onCreate(savedInstanceState: Bundle?) {
super.onCreate(savedInstanceState)
val binding = ActivityPhoneSizePraBinding.inflate(layoutInflater)
setContentView(binding.root)
if(Build.VERSION.SDK_INT >= Build.VERSION_CODES.R){
val windowsMatrix: WindowMetrics = windowManager.currentWindowMetrics
binding.textView.text = "width : ${windowsMatrix.bounds.width()}, height : ${windowsMatrix.bounds.height()}"
} else {
val display = windowManager.defaultDisplay
val displayMetrics = DisplayMetrics()
display?.getRealMetrics(displayMetrics)
binding.textView.text = "width: ${displayMetrics.widthPixels}, height : ${displayMetrics.heightPixels}"
}
}
}
