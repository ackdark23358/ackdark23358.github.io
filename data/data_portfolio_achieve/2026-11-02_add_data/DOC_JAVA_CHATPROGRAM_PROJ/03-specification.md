# 기술 명세

## 요구사항

| 번호 | 내용 |
| --- | --- |
| R1 | 서버 창에서 포트를 열고 닫을 수 있다. 기본 포트는 7777이다. |
| R2 | 클라이언트는 서버 IP, 포트, 대화명으로 접속한다. |
| R3 | 대화명은 공백 없이 1자 이상 12자 이하다. 이미 있는 이름은 거절한다. |
| R4 | 접속한 모든 클라이언트에 입장, 퇴장, 대화를 보낸다. |
| R5 | 대화 앞에는 말한 사람의 대화명이 붙는다. 클라이언트는 다른 사람 이름으로 말할 수 없다. |
| R6 | 클라이언트 가운데는 채팅방, 오른쪽은 대화상대다. 본인에게는 `(나)`를 붙인다. |
| R7 | 나가면 남은 사람에게 퇴장 안내를 보내고 목록에서 뺀다. 창을 그냥 닫아도 같다. |
| R8 | 다른 PC는 서버가 보여 주는 IPv4 주소와 같은 포트로 접속한다. |
| R9 | 한글 대화가 깨지지 않도록 입출력은 UTF-8이다. |
| R10 | 한 방은 최대 100명이다. 한 메시지는 500자까지다. |

## 사용 흐름

1. 사용자가 서버를 실행하고 **서버 실행**을 누른다.
2. 서버가 `ServerSocket`으로 모든 네트워크 인터페이스의 해당 포트를 연다.
3. 사용자가 클라이언트를 실행하고 IP, 포트, 대화명을 입력한 뒤 **접속**을 누른다.
4. 클라이언트가 `Socket`으로 연결하고 `JOIN 대화명`을 보낸다.
5. 서버가 이름을 검사해 목록에 넣은 뒤 `OK`, 입장 안내, 대화상대 목록을 보낸다.
6. 사용자가 입력창에 글을 쓰고 **전송** 또는 Enter를 누른다.
7. 서버가 그 접속의 대화명을 붙여 방 전체에 `CHAT`을 보낸다.
8. 사용자가 **나가기**를 누르면 클라이언트가 `QUIT`을 보내고 소켓을 닫는다.
9. 서버가 그 접속을 목록에서 빼고, 남은 사람에게 퇴장 안내와 새 목록을 보낸다.

서버 종료는 확인 뒤 열려 있는 소켓을 모두 닫는다. 클라이언트는 연결이 끊겼다는 안내를 보여 준다.

## 화면

### 채팅 서버

- 위: 포트, **서버 실행**, **서버 종료**, 실행 상태
- 가운데: 서버 로그. 시작, 이 컴퓨터 주소, 다른 PC용 주소, 입장, 퇴장, 대화
- 오른쪽: 접속자. `대화명`과 IP, 인원 수

### 채팅 클라이언트

- 위: 서버 IP, 포트, 대화명, **접속**, 접속 상태
- 가운데: 채팅방. 시각, 입장·퇴장 안내, `대화명: 내용`
- 오른쪽: 대화상대. 인원 수, 본인은 `이름 (나)`
- 아래: 입력창, **전송**, **나가기**

접속 전에는 입력과 전송이 꺼져 있다. 접속 중에는 IP, 포트, 대화명, 접속 버튼이 꺼져 있다.

## 접속 상태

클라이언트는 세 상태로 움직입니다.

| 상태 | 화면 | 다음 |
| --- | --- | --- |
| 대기 | 접속 버튼을 누를 수 있음 | 접속 시도 |
| 접속 중 | 나가기로 시도를 취소할 수 있음 | 입장 성공, 실패, 취소 |
| 입장 | 전송과 나가기 가능 | 대화, 나가기, 연결 끊김 |

입장 실패는 빈 이름, 공백, 12자 초과, 중복 이름, 정원 초과, 서버 종료입니다. 서버에 연결 자체가 안 되면 포트에 서버가 없는 경우가 많고, 클라이언트는 서버 실행 여부와 주소·포트를 확인하라는 안내를 보여 줍니다.

## 메시지 규칙

한 줄이 한 메시지입니다. 첫 칸까지가 명령이고 나머지가 내용입니다. 줄 끝은 개행입니다.

| 방향 | 형식 | 의미 |
| --- | --- | --- |
| 클라이언트 → 서버 | `JOIN 대화명` | 입장 요청 |
| 클라이언트 → 서버 | `CHAT 내용` | 대화. 이름은 클라이언트가 정하지 않음 |
| 클라이언트 → 서버 | `QUIT` | 나가기 |
| 서버 → 클라이언트 | `OK 대화명` | 입장 성공 |
| 서버 → 클라이언트 | `FAIL 이유` | 입장 거절 후 연결 종료 |
| 서버 → 클라이언트 | `SYSTEM 안내` | 입장 또는 퇴장 |
| 서버 → 클라이언트 | `CHAT 대화명` + 탭 + 내용 | 말한 사람을 서버가 붙인 대화 |
| 서버 → 모두 | `USERLIST 이름` + 탭 + 이름 | 현재 대화상대. 이름 순서는 입장 순 |

퇴장 안내는 나가는 사람에게는 다시 보내지 않습니다. 그 클라이언트는 자신이 나갔다는 문장을 화면에 남깁니다.

## 자료 흐름

```text
클라이언트 입력
    → 출력 버퍼에 CHAT 한 줄
    → 서버 수신 스레드
    → 그 소켓의 대화명을 붙임
    → 접속 중인 모든 출력 버퍼
    → 각 클라이언트 수신 스레드
    → 채팅방 문장과 대화상대 목록 갱신
```

서버의 접속 수락 스레드와 클라이언트마다의 수신 스레드는 별개입니다. 화면 갱신은 Swing 이벤트 스레드에서 합니다.

## 예외와 한계

- 포트가 이미 쓰이면 서버는 열리지 않고 다른 포트를 입력하라는 안내를 보여 줍니다.
- 접속 시도는 5초를 넘기면 실패로 처리합니다.
- 서버를 먼저 실행하지 않으면 클라이언트 접속은 거절됩니다.
- 다른 PC에서 막히면 Windows 방화벽에서 해당 자바 프로그램의 개인 네트워크 수신을 허용해야 합니다.
- 사설 IP는 실행할 때마다 서버 로그에 다시 표시합니다. 카드나 이 문서에 고정 주소로 적지 않습니다.
