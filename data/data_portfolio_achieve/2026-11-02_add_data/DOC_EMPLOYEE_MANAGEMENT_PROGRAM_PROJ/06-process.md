# 처리 명세

화면의 버튼은 `EmpDAO`의 메서드와 대응한다. 쿼리의 값은 `PreparedStatement`에 넣는다.

| 화면 동작 | DAO 메서드 | 처리 |
| --- | --- | --- |
| 창을 열 때, 전체목록 | `selectAll` | 사원번호 순으로 전체 조회 |
| 검색 | `search` | 이름, 직급, 부서명, 사원번호에 검색어가 포함된 행 |
| 부서 콤보박스 | `selectDepts` | 부서번호 순으로 부서 조회 |
| 초기화 | `nextEmpno` | 가장 큰 사원번호에 1을 더한 값 |
| 등록 | `insert` | emp에 한 행 추가 |
| 수정 | `update` | 사원번호를 제외한 값을 갱신 |
| 삭제 | `delete` | 그 사원을 관리자로 둔 행의 mgr을 비운 뒤 삭제 |

## 조회

`selectAll`과 `search`는 같은 조회 골격을 쓴다.

```text
emp e
  LEFT JOIN dept d ON e.deptno = d.deptno
  LEFT JOIN emp m  ON e.mgr = m.empno
```

검색은 아래 네 조건 중 하나라도 맞으면 포함한다. 검색어 앞뒤에 `%`를 붙인다.

- 사원 이름
- 직급
- 부서명
- 사원번호를 문자열로 본 값

이름, 직급, 부서명은 대소문자를 구분하지 않는다. 검색어가 비어 있으면 검색 버튼을 눌러도 전체 목록을 보여 준다.

## 등록

1. 입력 규칙을 검사한다. 맞지 않으면 경고만 보여주고 끝낸다.
2. `insert`로 한 행을 넣는다.
3. 검색어를 지우고 전체 목록을 다시 읽는다.
4. 방금 등록한 사원번호를 목록에서 선택한다.
5. 「사원이 등록되었습니다.」를 보여 준다.

같은 사원번호가 이미 있으면 「이미 사용 중인 사원번호입니다.」를 보여 주고 목록은 바꾸지 않는다.

## 수정

1. 목록에서 선택한 행이 없으면 경고를 보여 준다.
2. 입력 규칙을 검사한다. 사원번호는 수정 모드에서 바꿀 수 없다.
3. `update`로 이름, 직급, 관리자번호, 입사일, 급여, 수당, 부서를 갱신한다.
4. 검색 중이면 그 검색 결과를, 아니면 전체 목록을 다시 읽는다.
5. 같은 사원번호를 다시 선택하고 「사원 정보가 수정되었습니다.」를 보여 준다.

갱신된 행이 없으면 「해당 사원을 찾지 못했습니다.」를 보여 준다.

## 삭제

1. 선택한 사원이 없으면 경고를 보여 준다.
2. 「사원번호 이름 사원을 삭제할까요?」를 묻는다. 아니오이면 끝낸다.
3. 그 사원번호를 관리자로 가진 다른 사원의 `mgr`을 NULL로 바꾼다.
4. 해당 사원 행을 삭제한다. 두 문장은 한 트랜잭션이다.
5. 목록을 다시 읽고 신규 등록 모드로 돌아간 뒤 「삭제되었습니다.」를 보여 준다.

부서 행은 삭제하지 않는다. 관리자 번호에 외래 키가 없으므로, 다른 사원이 그 사람을 관리자로 두고 있어도 삭제는 막히지 않는다. 대신 그 관리자 번호는 비워진다.

## 오류

데이터베이스 연결이나 쿼리가 실패하면 오류 대화상자에 실패 이유와 예외 메시지를 보여 준다. 시작 시점에 테이블을 만들지 못하면 창을 열지 않고 오류를 보여 준다.
