# 프로젝트 소개

## 배경

에듀펜 자바 과정에서 사원 정보를 다루는 프로그램을 만들었다. 당시 구성으로 기억나는 것은 DAO, DTO, Swing 화면, 사원에 대한 등록·조회·수정·삭제였다. 과정 이름에는 JSP도 들어 있었지만, 다시 만든 이 프로그램의 화면은 Swing이다.

[프로젝트 아카이브](https://ackdark23358.github.io/portfolio_achieve/index.html)의 PROJ_15는 그 수강 폴더를 가리킨다. 폴더 이름에는 2017년부터 2019년까지의 자바 과정과 데이터 유실이 적혀 있고, 2026년 10월 18일에 열어 보았을 때 파일이 없었다. 이 구현은 그 빈 기록을 소스와 실행 화면으로 다시 채우기 위한 것이다.

## 범위

포함하는 것:

- 사원 한 명의 정보를 보여주는 Swing 화면
- 사원 목록 조회와 조건 검색
- 사원 등록, 수정, 삭제
- 부서 목록을 콤보박스에서 선택
- 화면과 데이터베이스 사이의 DTO, DAO 분리
- 프로그램을 처음 실행할 때 테이블과 샘플 데이터 생성

포함하지 않는 것:

- JSP, 서블릿, 브라우저 화면
- 로그인과 권한
- 부서 자체의 등록·수정·삭제
- Oracle, MySQL 서버 설치

## 사용자

프로그램을 실행하는 한 사람이 사원 정보를 직접 다룬다. 별도의 로그인 사용자는 없다.
