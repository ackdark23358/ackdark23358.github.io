과제 주제

C언어과제4

다음 프로그램에서 각 변수가 메모리에 들어가 있는 주소값이 십진수로 아래와 같다고 할 때 printf()문의 출력 결과를 쓰시오.(6주차 1차시)

num의 주소 = 124560, p의 주소=124564

(프로그램)
#include
main()
{
int num=20; int *p = &num ;
printf("*p = %d\n", *p);
printf(" &num = %d\n", &num) ;
printf("p = %d\n", p) ;
printf(" &p=%d\n", &p ) ;
return 0 ;
}

과제에 대한 답변

========================
출력결과
========================
*p = 20
 &num = 1234560
p = 1234560
 &p = 1234564
