순수함수
부작용이 없는 함수 동일한 입력인자에 대해서 항상같은 결과
fun sum(a: Int, b: Int) = a+b

같은 인자에 대해서 항상 같은 값반환
함수 외부의 어떤 상태도 바꾸지 않는다.

순수함수가 아닌경우
check(){ val test = User.grade() if(test !=null) process(test)}
test가 User.grade()의실행결과에 따라 달라지고 check()함수에 없는 외부의 User 객체를 사용 A가 나온다음 유저의 B가나올 수 있다.

fun main(){ val num1 = 10, val num2 = 3, val result = noPureFUnction 
} 외부의 값변경
fun noPureFunction(a:Int, b: Int): Int{ return a+ b + global }  외부값에 의해 변경

순수함수를 사용하게되면 함수들과 조합해도 부작용이 없다.
병행작업시 안전하고 값을 추적하고 예측 할 수 있어서 테스트와 디버깅에 유리하다.

람다식
익명함수의 하나의 형태로 이름 없이 사용 및 실행이 가능, 람다대수로 부터 유래
{x, y => x+ y }
람다식의 이용 람다식은 고차함수에서 인자로 넘기거나 결과값으로 반환등을 할 수 있다. 람다식도 일종의 함수

고든이라는 사람이 있는데 입사를 했는데 사고가 난다. 고든은 빠루로 외계인들을 떄려잡게된다.
 화살표로 외계인들을 때려잡는다. 화살표가 무조건 들어가는건아니다.

일급객체 First Class citizen 일등시민 => 함수의 인자, 반환값에 사용, 변수에 담기가능
1급함수라고도 한다.
