애플리케이션
백엔드 개발에서의 애플리케이션은 특정 기능을 제공하는 프로그램을 가리킨다. 사용자 인터페이스도 있고 자료를 처리하거나 사용자와 상호작용하는 기능이 모두 포함된다. 

API
API는 Application Programming Interface의 줄임말로 애플리케이션 간에 자료를 주고받으면서 특정 기능을 실행 한다.

RESTful API
웹은 처음 발표도리 때무터 HTTP라는 프로토콜을 기본으로 햇다. HTTP프로토콜은 클라이언트와 서버 사이에 자료를 주고받을때 사용하는 규칙이라고 할 수 있다.
