추가 학습 자료

PROJ_08_add_doc은 책 앞부분과 1장부터 11장 기록, 다이어그램, 코파일럿 인증 메모입니다. 책 본문은 옮기지 않고 장별 주제만 모았습니다. 필기 요약을 정리할 때 뤼튼을 사용했습니다.

  • 앞부분 · 1–2장

    역자 김연지, 저자 레오 포터와 다니엘 전가로, 기술 편집 피터 모건입니다. VS Code에서 코파일럿을 쓰려고 뤼튼 검색으로 책을 찾았다고 적혀 있습니다. 1장은 LLM, 하향식 설계, 테스트, 저작권, 보안, 프롬프트 엔지니어링입니다. 2장은 VS Code, 코파일럿 구독과 확장, 파이썬 인증, CSV를 읽어 matplotlib로 그리는 연습입니다.

  • 3–5장

    함수는 한 가지 일을 하고, 독스트링으로 입력과 출력을 적습니다. 노트에는 더 큰 수를 고르는 함수 이름이 lager로 적혀 있습니다. 4장은 코드를 읽고 Copilot Explain으로 설명을 받는 기록입니다. 5장은 for와 while, 딕셔너리, open, 모듈입니다.

  • 6–7장

    6장은 테스트를 건너뛰는 슈퍼 버그, 블랙박스와 화이트박스, doctest와 pytest, TDD입니다. 7장은 저자 식별의 하향식 설계입니다. 시그니처는 평균 단어 길이, 서로 다른 단어 비율, 한 번만 나온 단어 비율, 문장당 단어 수, 문장 복잡도 다섯 가지이고, 가중치는 11, 33, 50, 0.4, 4입니다.

  • 8–9장

    8장은 print와 중단점으로 버그를 찾고, 코파일럿 챗과 함수 설계 주기를 적습니다. 9장은 반복 작업 자동화입니다. 노트에 나온 clean_email_letter.py, combine_report.py는 이 폴더에 없고, 사진 합치기 스크립트가 그 실습으로 남아 있습니다. 파일을 쓰기 모드로 열면 덮어쓴다는 주의가 있습니다.

  • 10–11장

    10장은 매직 넘버를 피하고, 리스트 컴프리헨션과 이벤트 중심 프로그래밍, 숫자 맞히기와 보카드 게임 실습입니다. 노트 속 10_practice.py, 10_2_practice.py는 폴더에 없습니다. 11장은 GoF 디자인 패턴, 뒤집힌 상호작용, 페르소나 패턴입니다. 코파일럿 챗이 일부 프롬프트 패턴을 거부할 수 있다고 적혀 있습니다.

  • 다이어그램 · 인증

    프로젝트 폴더에 함수 설계 주기와 저자 식별 하향식 설계 drawio가 있습니다. 자료 폴더에는 보카드 게임 다이어그램 두 개와 모듈 작업을 넣은 설계 주기 drawio, 임시 백업 두 개가 있습니다. 코파일럿 확장이 인증되지 않을 때 VS Code에서 Developer: Reload Window를 실행해 풀었다고 적혀 있습니다.

실행 화면

2026년 10월 17일에 7_practice.py를 실행하면 독테스트 14개가 통과합니다. lowest_score는 마지막 독테스트 호출보다 뒤에 정의되어, 그 실행에는 포함되지 않습니다. 파일을 모두 읽은 뒤 다시 돌리면 그 예시까지 18개가 통과합니다. 네 편의 미지 문서는 같은 날 process_data로 비교했습니다. 파일 맨 아래는 이 함수를 호출하지 않습니다.

간단 설명

7_practice.py는 구두점을 벗긴 단어를 세어 다섯 숫자 시그니처를 만듭니다. known_authors의 네 파일은 주홍색 연구, 위대한 유산, 오만과 편견, 톰 소여입니다. 미지 문서는 네 사람의 서명, 두 도시 이야기, 에마, 허클베리 핀입니다. 가중치를 곱한 차이 합이 가장 작은 파일 이름을 돌려줍니다.

pictures_comine.py는 pictures1과 pictures2를 돌며 pictures_combined 안의 파일과 내용이 같으면 건너뛰고, 다르면 복사합니다. 이름이 겹치면 .png 앞에 _를 붙입니다. 그 두 폴더는 2026년 10월 17일 프로젝트 안에 없었습니다.

핵심 기능

기능 하는 일
단어·문장 정리 양 끝 구두점을 벗기고, 문장과 구를 나눕니다. 구를 나누는 함수 이름은 get_pharse입니다.
시그니처 글 하나의 특징 다섯 개를 리스트로 만듭니다.
가장 가까운 저자 파일 알려진 글과 미지 글의 차이 합이 가장 작은 파일 이름을 고릅니다.
독테스트 파일을 실행하면 그때까지 정의된 예시 14개가 통과합니다.
사진 합치기 내용이 같은 png는 건너뛰고, 이름만 겹치면 _를 붙여 복사합니다. 원본 폴더는 이 프로젝트에 없습니다.

파일에서 이은 기록

  • readme 문자열 패턴과 소수점 오차, 테스트가 정확히 통과했는지는 남아 있는 의문으로 적혀 있습니다. 저자를 알 수 없는 파일을 어느 정도 가려 낼 수 있다고도 적혀 있습니다.
  • 2026-10-17 파일 실행은 14개 통과입니다. 모듈을 모두 읽은 독테스트는 18개 통과입니다. unknown4는 허클베리 핀인데 점수 3.84로 디킨스, 11.34로 트웨인이어서 디킨스 파일 이름이 반환되었습니다.
  • 독스트링 split_string 설명은 한 번만 나온 단어 비율을 적고, 예시는 구분자로 나누는 동작과 맞습니다.
  • 사진 스크립트 파일 이름은 pictures_comine.py입니다. pictures1, pictures2는 폴더에 없어 복사 함수는 호출하지 않았습니다.
