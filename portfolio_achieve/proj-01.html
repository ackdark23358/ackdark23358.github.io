파이썬 학습과 댓글 게시판

Do it 파이썬 웹개발 파이날 미니프로젝트(클라우드 타입으로 호스팅까지) 폴더와 PROJ_01_add_doc을 함께 정리한 기록입니다. 『Do it! 파이썬』 필기는 뤼튼으로 요약하고, 『Do it! 점프 투 파이썬』 실습은 OpenAI로 문서와 보고서로 남겼습니다. 실행 프로그램은 조코딩 게시판 예제를 참고한 Node.js 댓글 게시판이며, 아래 화면은 배포 전 로컬 시험입니다. 실제 호스팅은 프로젝트 완료 후 시간이 오래 지나 이 페이지에 넣지 않았습니다.

추가 학습 자료

PROJ_01_add_doc의 필기, 실습 스크린샷, 학습 보고서입니다. 책 본문은 옮기지 않고, 점프 투 파이썬 학습 기록 문서의 스크린샷을 장별 제목과 함께 아래에 두었습니다.

  • Do it! 파이썬

    뤼튼으로 요약한 필기입니다. 특징과 라이브러리, PATH 설치, 들여쓰기, 숫자와 문자열, 리스트, 튜플, 딕셔너리, pickle, Tkinter, 정규 표현식까지 다룹니다.

  • Do it! 점프 투 파이썬

    CMD와 IDLE에서 실습한 화면을 OpenAI로 문서로 묶었습니다. 스크린샷 기록은 2025년 8월 21일부터 9월 8일까지 있습니다.

  • 1장 파이썬 설치, 출력, 반복. 2025년 8월 21일.
  • 2장 별 연산자로 문자열을 곱해 출력. 2025년 8월 22일.
  • 3장 if 문. 2025년 8월 23일.
  • 4장 기본 매개변수를 잘못 썼을 때의 오류. 2025년 8월 25일.
  • 5장 3과 5의 배수 합, 게시판 페이징, 구구단, 메모장, 탭을 공백 4칸으로 바꾸기, 하위 디렉터리 검색. 2025년 9월 8일.
  • 6장 EUC-KR 저장, 클래스, 클로저와 데코레이터, 제너레이터, 이터레이터, 타입 힌팅, mypy.
  • 8장 여러 줄과 여러 문자열 매칭.

파이썬 학습 보고서의 결론은, 문법과 자료구조, 데이터 처리, GUI, 정규 표현식, 데이터 저장까지 익혔고 이후에는 데이터 분석과 인공지능 라이브러리로 넓히겠다는 내용입니다. 점프 투 파이썬 보고서는 기초 문법, 표준 라이브러리, 타입 힌팅, 이터레이터와 제너레이터를 범위로 잡고, 예외 처리와 인코딩, 테스트 자동화는 다음 과제로 적어 두었습니다.

실행 화면

2026년 10월 17일, 호스팅 환경을 구성한 뒤 배포 전에 시험하는 환경에서 프로젝트 폴더의 node index.js로 띄우고 찍었습니다. 실제 호스팅은 프로젝트 완료 후 시간이 오래 지나 넣지 않았습니다. 확인용으로 넣은 댓글은 화면을 남긴 다음 삭제했습니다.

간단 설명

브라우저의 폼이 댓글 내용을 서버로 보내고, Express가 그 값을 받아 Sequelize로 SQLite에 저장합니다. 화면은 EJS 파일 하나에서 목록, 수정, 삭제, 등록을 모두 그립니다. 등록·수정·삭제가 끝나면 목록 주소로 다시 이동합니다.

데이터 모델 이름은 Comments이고, 사용자가 입력하는 필드는 content 하나입니다. 번호와 작성·수정 시각은 Sequelize가 행을 만들 때 붙입니다. 스타일시트는 없고, 브라우저 기본 글자와 폼으로 동작만 확인할 수 있게 되어 있습니다.

사용 도구

  • Node.js · Express 4.21

    포트 3000에서 목록과 등록, 수정, 삭제 요청을 받습니다.

  • EJS 3.1

    views/index.ejs가 댓글 배열을 받아 목록과 폼을 그립니다.

  • Sequelize 6.37

    Comments 모델을 정의하고 조회, 생성, 수정, 삭제를 호출합니다.

  • SQLite 5.1

    데이터베이스 파일은 프로젝트 안의 database.sqlite입니다.

  • Cloudtype

    호스팅 환경을 준비하는 대상으로 적어 두었습니다. 프로젝트 완료 후 시간이 오래 지나 실제 호스팅은 이 페이지에 넣지 않았고, 화면은 배포 전 시험에서 남겼습니다.

  • 조코딩 예제

    README에는 라이선스를 간접적으로 조코딩 예제를 따른 것으로 적어 두었습니다.

실제 호스팅
프로젝트 완료일인 2025년 2월 17일 이후 시간이 오래 지나, 실제 호스팅은 이 페이지에 넣지 않았습니다. README에 적어 둔 Cloudtype 주소와 GitHub 저장소는 2026년 10월 17일 확인 때 모두 404였고, 주소는 적어 둔 그대로 두었습니다.

핵심 기능

네 가지 모두 폼 전송으로 동작하고, 처리가 끝나면 목록으로 리다이렉트합니다.

기능 요청 하는 일
목록 GET / 저장된 댓글을 모두 읽어 번호와 내용, 수정·삭제 폼을 보여 줍니다.
등록 POST /create content로 행을 만든 뒤 목록으로 돌아갑니다.
수정 POST /update/:id 해당 번호의 내용을 입력칸의 새 값으로 바꿉니다. 기존 문장은 칸에 채워 두지 않습니다.
삭제 POST /delete/:id 해당 번호의 행을 지우고 목록으로 돌아갑니다.

책과 README에서 이은 기록

게시판 완료일은 폴더의 완료일 2025년 02-17.txt 파일 이름입니다. 점프 투 파이썬 스크린샷은 그 이후인 2025년 8월에서 9월 기록이라, 게시판 완료일과 학습 일지를 한 날짜로 합치지 않았습니다. 아래는 게시판 폴더의 README.txt를 페이지 문장으로 옮기고, 현재 소스와 어긋나는 부분만 덧붙인 것입니다.

  • 데이터베이스 SQLite를 사용합니다. 데이터베이스 파일을 Git에 올릴지는 선택입니다.
  • 게시판 글 작성, 등록, 수정, 삭제를 구현했습니다.
  • 데이터 흐름 index.ejs와 index.js가 폼으로 값을 주고받고, SQLite에 저장합니다. ORM은 Sequelize입니다.
  • CORS README에는 CORS를 부분적으로 사용했다고 적혀 있습니다. 현재 package.json과 index.js에는 CORS 설정이 없습니다.
  • 라이브러리 README는 EJS 3.1.10과 Express 4.21.2를 적었습니다. 소스에는 Sequelize 6.37.5와 sqlite3 5.1.7이 함께 들어 있습니다.
