# 실행 방법

2026년 11월 2일 확인에 사용한 JDK는 26입니다. 소스는 자바 8에서도 컴파일되는 문법으로 작성했습니다. 문자 인코딩은 UTF-8입니다.

## 이클립스

1. **File > Import > Existing Projects into Workspace**로 채팅 프로그램 폴더를 엽니다. 프로젝트 이름은 `JavaChat`입니다.
2. 한글이 깨지면 프로젝트 **Properties > Resource > Text file encoding**을 UTF-8로 지정합니다.
3. `src/chat/server/ChatServer.java`를 **Run As > Java Application**으로 실행합니다.
4. 포트 `7777`을 확인하고 **서버 실행**을 누릅니다. 상태가 `실행 중`이면 접속을 받을 수 있습니다.
5. `src/chat/client/ChatClient.java`를 같은 방법으로 실행합니다. 사람을 더 넣으려면 클라이언트를 다시 실행합니다.
6. 서버 IP `127.0.0.1`, 포트 `7777`, 대화명을 입력하고 **접속**을 누릅니다.

## 배치 파일

PATH에서 `java`와 `javac`를 쓸 수 있어야 합니다.

```bat
run-server.bat
run-client.bat
```

인자로 바로 열 수도 있습니다.

```bat
run-server.bat 7777
run-client.bat 127.0.0.1 7777 홍길동
run-client.bat 127.0.0.1 7777 김철수
```

서버 인자는 포트입니다. 클라이언트 인자는 IP, 포트, 대화명 순서입니다.

## 대화와 나가기

1. 아래 입력창에 글을 쓰고 **전송** 또는 Enter를 누릅니다.
2. **나가기**는 채팅방만 나갑니다. 클라이언트 창은 남아 있어 다시 접속할 수 있습니다.
3. 창의 닫기는 접속 중이면 확인 후 프로그램을 끝냅니다.
4. 서버의 **서버 종료**는 확인 후 모든 접속을 끊습니다.

같은 컴퓨터에서 시험할 때 서버 IP는 `127.0.0.1`입니다. 클라이언트가 `서버에 연결할 수 없습니다`를 보여 주면, 서버 창이 없거나 **서버 실행** 전입니다. 포트가 서버와 같은지도 봅니다.

## 다른 PC

1. 서버와 클라이언트를 같은 네트워크에 둡니다.
2. 서버 로그의 `다른 PC에서 접속할 주소`를 읽습니다.
3. 다른 PC 클라이언트의 서버 IP에 그 주소를 넣고, 포트는 서버와 같게 합니다.
4. Windows가 Java 수신을 물으면 개인 네트워크를 허용합니다.

`127.0.0.1`은 서버가 켜져 있는 그 컴퓨터에서만 연결됩니다.
