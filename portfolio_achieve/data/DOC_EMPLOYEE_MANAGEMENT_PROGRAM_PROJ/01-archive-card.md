# 아카이브 카드 문안

[프로젝트 아카이브](https://ackdark23358.github.io/portfolio_achieve/index.html)의 카드는 프로젝트 소개, 간단 설명, 사용 도구, 실행 환경, 핵심 기능으로 구성된다. 현재 마지막 카드는 PROJ_17이므로, 이어서 넣을 때는 PROJ_18이 된다. 아래 문안은 그 칸에 옮기기 위한 초안이다.

카드에 올릴 대표 화면은 `img/01_조회.png`이다. 등록, 수정, 삭제는 `img/02_등록.png`, `img/03_등록완료.png`, `img/04_수정완료.png`, `img/05_삭제.png`를 함께 둔다.

## 제목

PROJ_18 · 2026.11.02  
사원관리 프로그램

## 프로젝트 소개

에듀펜 자바 과정에서 만들던 사원관리 프로그램을 다시 구현한 데스크톱 프로그램이다. 아카이브의 PROJ_15는 2017–2019 수강 기록만 남아 있고 소스와 캡처가 유실된 상태였다. 화면은 Java Swing이고, 사원 한 명의 값은 DTO에 담으며, 저장과 조회는 DAO와 JDBC가 맡는다.

## 간단 설명

왼쪽 입력란과 오른쪽 사원 목록으로 이루어진다. 목록에서 사원을 누르면 입력란에 값이 채워지고, 등록·수정·삭제로 사원 정보를 다룬다. 이름, 직급, 부서명, 사원번호로 검색할 수 있다. 데이터는 실행 폴더의 H2 파일에 남는다. 처음 실행하면 교재용 사원 14명과 부서 4개가 들어 있다.

## 사용 도구

Java, Swing, JDBC, H2, DAO, DTO

## 실행 환경

Windows. Java 11 이상. 프로젝트 폴더에서 `run.bat`을 실행한다. 데이터베이스 파일은 `data/empdb`이고, 별도 Oracle이나 MySQL 설치는 없다. 화면 캡처는 2026년 11월 2일에 저장했다. 호스팅 주소는 없다.

## 핵심 기능

사원 목록 조회, 이름·직급·부서·사원번호 검색, 사원 등록, 수정, 삭제, 목록 정렬
