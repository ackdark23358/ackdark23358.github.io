# 자료 사전

## dept

부서. 화면에서는 콤보박스로만 고르고, 부서 자체를 추가하거나 지우지는 않는다.

| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| deptno | INT, 기본키 | 부서번호 |
| dname | VARCHAR(20), 필수 | 부서명 |
| loc | VARCHAR(20) | 위치 |

처음 생성될 때의 값:

| deptno | dname | loc |
| --- | --- | --- |
| 10 | ACCOUNTING | NEW YORK |
| 20 | RESEARCH | DALLAS |
| 30 | SALES | CHICAGO |
| 40 | OPERATIONS | BOSTON |

## emp

사원. `deptno`는 `dept`를 참조한다. 관리자 번호 `mgr`에는 외래 키를 두지 않아서, 관리자를 지울 때 다른 사원의 관리자 번호만 비운다.

| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| empno | INT, 기본키 | 사원번호 |
| ename | VARCHAR(20), 필수 | 이름 |
| job | VARCHAR(20) | 직급 |
| mgr | INT | 관리자 사원번호. 없으면 NULL |
| hiredate | DATE | 입사일. 없으면 NULL |
| sal | INT, 필수 | 급여 |
| comm | INT | 수당. 없으면 NULL |
| deptno | INT | 부서번호. `dept.deptno` 참조 |

## EmpDTO

데이터베이스 컬럼과 같은 값에, 조인 결과인 `dname`, `mgrName`을 더한다. `mgr`와 `comm`은 비울 수 있어 `Integer`이고, `hiredate`는 `LocalDate`이다.

## 화면 입력 규칙

| 항목 | 규칙 |
| --- | --- |
| 사원번호 | 필수. 1 이상의 정수. 등록 때 이미 있으면 거부 |
| 이름 | 필수. 20자 이하 |
| 직급 | 선택. 20자 이하. 목록에서 고르거나 직접 입력 |
| 관리자번호 | 선택. 비우거나 정수 |
| 입사일 | 선택. 비우거나 `yyyy-MM-dd` |
| 급여 | 필수. 0 이상의 정수. 천 단위 쉼표는 무시 |
| 수당 | 선택. 비우거나 0 이상의 정수 |
| 부서 | 필수. 콤보박스의 부서 중 하나 |

새 입력 모드에서는 다음 사원번호를 `MAX(empno) + 1`로 채워 둔다. 사원이 없으면 1001부터 시작한다. 샘플 데이터가 있으면 7934 다음인 7935가 제안된다.
